# Мобильные иллюстрации главной — 5 ноября 2026

Четыре отдельные квадратные композиции встроенного ImageGen, созданные по
фирменным сценам с курочкой. Это новые рисунки для узкого вертикального экрана.
Персонаж крупнее относительно еды; три целых продукта собраны над ним.
Оставлены две небольшие пары штрихов. У Фибриков нет срезов.

Рабочие файлы: fibriki.webp, meatballs.webp, nuggets.webp, lulia-mini.webp.
Каждый WebP — 960 × 960, quality 92, с прозрачностью. PNG-мастера и точные
*-prompt.txt сохранены рядом; источники и размеры — в generated-assets.json.
layout.json хранит размеры холста для адаптивной композиции без обрезания.

Picture выбирает эти изображения только до 699 px в вертикальном положении.
При повороте телефона используется широкая сцена в отдельном двухколоночном
макете. Неактивные source загружаются по выбору/в свободное время; автопоказа нет.
