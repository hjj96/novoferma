# Мобильные сцены v2 — 5 ноября 2026

Правка встроенным ImageGen по предыдущим PNG mobile-v1: еда немного уменьшена
и разнесена по свободной дуге выше персонажа. Все три целых продукта отделены
друг от друга и от клюва, гребня и крыльев курочки видимым воздухом. Сохранены
персонажи, смешение фото/рисованного стиля и две небольшие пары штрихов.

Файлы fibriki.webp, meatballs.webp, nuggets.webp, lulia-mini.webp — 960×960,
quality 92, с прозрачностью; PNG-мастера 1254×1254 и точные *-prompt.txt рядом.
Источники и итерации — fibriki-provenance.json и spacing-assets.json.
layout.json сохраняет весь квадрат: без обрезания и увеличения по alpha bbox.

Подключение только через portrait source на ширинах до 699 px. Версия для ПК,
горизонтального телефона и CSS сохранены. Старые файлы mobile-v1 не изменены.
Снимки и ревью: output/research/mobile-art-spacing-2026-11-05/ рабочего проекта.
