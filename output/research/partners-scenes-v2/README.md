# Новая страница партнёров: сцены и действия

16 октября 2026. Заменяет фотографию «Идея подачи» на странице партнёров и предыдущую товарную сетку. Блоки «О нас», каталог и контакты сохраняют свои самостоятельные изменения.

## Состав

1. «Вкусное партнёрство» — две фирменные курочки пожимают крылья. Основное действие — обсудить сотрудничество; дополнительное — выбрать формат.
2. Навигация по трём задачам: магазины, кафе/рестораны и собственная торговая марка.
3. «На полку. В меню.» — цельная морозильная витрина с упаковками Новофермы. Каталог и отдельные запросы по поставкам/HoReCa.
4. «Ваш бренд. Наш продукт.» — цветные упаковки с надписью «Ваша марка», подпись «Концепция оформления СТМ», переход к запросу СТМ.
5. Отдел заказов: видимые почта и телефон, переключатель направления, компания, город, контакт, комментарий. Кнопки сцен выбирают соответствующее направление. Форма составляет письмо через почтовое приложение; пользователь отправляет его сам. Запрос также можно скопировать. Без доступа к буферу показывается выделенный текст для ручного копирования.

На телефоне порядок каждой сцены — заголовок, иллюстрация, пояснение и действия. Изображения не обрезаются, текст не встроен в графику. Для всех сцен сохранены исходники PNG и промпты ImageGen.

## Что взято из практики

В официальных B2B интерфейсах производителей отдельно доступны ассортимент, решения по задачам оператора и прямой контакт: [Lamb Weston](https://www.lambweston.com/en.html), [каталог McCain Foodservice](https://www.mccainfoodservice.co.uk/products). Для этой страницы из этого сделан проектный вывод: посетителю нужен выбор сценария и конкретное следующее действие, а не декоративная сервировка. Это дизайнерская интерпретация, не универсальная доказанная норма.

[Карточка ромштекса ВкусВилла](https://vkusvill.ru/goods/romshteks-appetitnyy-s-zelenyu-20790/) и [карточка фрикаделек](https://vkusvill.ru/goods/frikadelki-klassicheskie-iz-myasa-tsyplyat-broylerov-86522/) указывают ООО «Новоферма» как изготовителя продукции под маркой магазина. Это основание для общей формулировки о выпуске под торговыми марками; оформление новых упаковок остаётся концептуальным. Отдельные цены, мощности, география, минимальная партия, сроки и разработка рецептуры не обещаются.

Контакты отдела заказов и собственный ассортимент сохранены из подтверждённой базы проекта: `../site-polish/content-sources.md`, `../novoferma-context-2026-10-08.md`, `../../concept/products.json`.
