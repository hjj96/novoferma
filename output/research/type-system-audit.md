# Аудит типографики и элементов управления

Дата: 25 сентября 2026. Снимок состояния перед финальным проходом главной страницы. Проверены `style.css`, `assets/fonts/font-face.css`, `depth.css`, генератор `scripts/build_site.py` и фактические computed styles в Chromium для 7 типов страниц при ширинах 1440, 768, 375 и 320 px. Данные: `tmp/type-audit.json`; скрипт: `tmp/type-audit.cjs`. Это рекомендации до внедрения, а не протокол проверки исправленной версии.

## Что уже работает

- Основной шрифт единый: локальный Onest (`Novoferma Sans`), заголовки обычно 850, кнопки 650.
- Все рукописные акценты используют один Caveat (`Novoferma Hand`) 500. Чужих рукописных гарнитур на рабочих страницах нет.
- Rubik (`Novoferma Poster`) 850 обоснованно выделен только для главного слогана; его характер следует сохранить.
- Основной текст на кремовом фоне имеет хороший контраст: `#795e4c` / `#fff5e3` — 5,52:1; коричневый — 13,45:1.
- Кнопки первого уровня имеют хороший контраст и ясный силуэт. Большинство CTA имеют высоту 49–53 px.

Цель 44 px — улучшение удобства на телефоне, а не утверждение, что каждый текущий контрол нарушает WCAG: WCAG 2.2 AA допускает меньшие цели с достаточным расстоянием. Маленькие круговые стрелки карточек — часть большой ссылки, поэтому не требуют самостоятельной зоны 44 px.

## Предлагаемая система ролей

| Роль | Гарнитура и начертание | Десктоп → телефон | Цвет / применение |
|---|---|---|---|
| Главный слоган | Rubik 850 | Текущее масштабирование по ширине колонки | Кремовый на оранжевом; сохранить текущее начертание |
| Название страницы | Onest 850 | 94–126 → 54–72 px по длине | Коричневый либо крупный оранжевый; контакты могут остаться особым плакатом |
| Заголовок раздела | Onest 850 | 64–76 → 44–48 px | Коричневый / кремовый на тёмном |
| Внутренний заголовок | Onest 850 | 36–48 → 32–38 px | Та же роль цвета, не рукописный |
| Товарное имя | Onest 800–850 | 28–32 → 21–23 px | Коричневый, line-height 1,08–1,12 |
| Текст | Onest 400 | 16–18 → 16 px | Коричневый либо `--muted` на светлом; светлый тёплый на коричневом |
| Кнопка | Onest 650 | 13–14 px | Кремовый / коричневый; минимум 48 px обычная, 44 px компактная |
| Служебная подпись | Onest 650–750 | 11–12 px | `--muted` или основной тёмный; минимум 12 для управляющих надписей |
| Hand: выразительный | Caveat 500 | 38–44 → 30–34 px | Hero, короткий акцент intro |
| Hand: заметка | Caveat 500 | 32–36 → 27–30 px | Aside, брендовая заметка, товарная заметка |
| Hand: подпись | Caveat 500 | 26–28 → 24–26 px | Фото, footer, бумажная заметка |
| Hand: «к столу!» | Caveat 500 | Текущее 47–70 px | Самостоятельный крупный композиционный акцент, допустимое исключение |

Роли не предполагают механически одинаковый размер каждого заголовка: важно постоянство начертания, межстрочного интервала, цвета и смысловой иерархии. Масштаб крупных плакатных фраз зависит от композиции PDF.

## Контраст: что сохранять

- `#301709` на оранжевом `#ec5812` — **4,77:1**: годится для обычного текста.
- `#402111` на оранжевом — **4,14:1**: годится для крупной рукописной фразы от 24 px, не для мелких подписей.
- Кремовый на оранжевом — **3,25:1**: годится для крупных заголовков; не делать мелкие CTA/служебные надписи просто кремовым по оранжевому без отдельного фона.
- Рукописное золото `#deb578` на коричневом — **7,61:1**.
- Текущий цвет «к столу!» на зеленом — **3,97:1**, при 47–70 px нормален.
- Обводки карточек и стрелок — декоративные, рядом есть ясные текстовые ссылки; не принимать их контраст за контраст текста.

## Проверка после внедрения

1. Дождаться локальных шрифтов (`document.fonts.ready`) перед снимками и измерениями.
2. Ширины 320, 375, 700, 768, 1440; особенно 699/700 — граница двухколоночного protein/hero.
3. Проверить главную, все 6 основных страниц и длинные названия товара.
4. Проверить зоны нажатия, переносы, видимость focus-ring, поиск и мобильный dialog.
5. Не допускать горизонтального скролла из-за повёрнутой рукописи; декоративные элементы не должны закрывать CTA.
6. Повторить проверки с `prefers-reduced-motion: reduce`, затем обычное движение.
